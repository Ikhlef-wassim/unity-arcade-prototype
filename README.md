# Unity Arcade Prototype

A 2D/3D Unity C# gameplay prototype repository configured with Unity ignore rules and Git LFS asset tracking.

## Repository Structure
- `Assets/Scripts/` — Modular C# `MonoBehaviour` gameplay controllers and mechanics
- `ProjectSettings/` — Unity project and input settings (add when opening in Unity Hub)
- `Packages/` — Unity Package Manager manifest

## Tech Stack
- **Unity**
- **C#**
- **Git & Git LFS**
